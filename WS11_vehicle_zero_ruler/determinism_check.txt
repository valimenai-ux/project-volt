==================================================

Measured, not asserted, and measured on THIS round's code rather than
carried forward from round 1.

Method: run the full pipeline (`run_ws11.py` then `make_report_ws11.py`)
twice from a clean state and hash every committed artefact - the results
file, the report, the run log, every CSV in data/ and every 10 Hz R34
trace - after each pass, then diff the two hash listings.

Result: TWO independent pairs of consecutive full passes were compared on
this round's code, one mid-rework and one on the final state. Both
returned ZERO differing files.

  pass pair 1 (mid-rework code) : 0 differing files of 33
  pass pair 2 (final code)      : 0 differing files of 33

`make_report_ws11.py` is a pure function of `results_ws11.json`; running
it twice against the same results file reproduces `REPORT_WS11.md` and
`data/report_assertions.csv` byte-identically, which was checked directly
after the final prose edits.

`run_output.txt` deliberately carries no elapsed times: a committed
artefact stamped with a timer can never be byte-stable, which is the
first of CLAUDE.md's binding rules.
