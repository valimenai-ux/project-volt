## 3. New findings

### WS2-F11 — MATERIAL. The cable table and the inverter rating both exclude the workstream's own governing sustained case: the 20% crawl draws 644 A_pk = 455 Arms phase current, vs a motor run sized at 299 Arms (120 mm², 320 A ampacity) and an inverter rated "500 A 10-min"

**What is wrong.** F10's fix made cable sizing voltage-consistent, but the sizing duty case for the `inverter_to_motor` run is S2 at the floor (299 Arms). The crawl — which §3 declares steady/indefinite with oil spray, which WS2-E1 says WS2 "has built for", and which F8 just established as the loop-sizing case — puts **643.9 A amplitude = 455 Arms through each phase conductor for minutes-to-indefinite** (re-derived; it is the MTPA minimum for 510 Nm, so no control strategy reduces it). That is 142% of the chosen cable's 320 A ampacity, roughly 2× rated I²R heating, sustained. The same current sits above the inverter's own published rating envelope in §2.3 ("660 A peak / **500 A 10-min**"): 644 A_pk indefinitely is beyond the 10-min class, yet §3's crawl rows are "steady... pass". The stated convention — "every run is sized at the window floor, the lowest bus voltage at which its **sustained power** must flow" — is the tell: the crawl's power (~90 kW) is unremarkable, but its *current* is torque-driven, not power-driven, which is exactly how a power-based sizing set misses it. This is the F8 class one column over: the governing case is printed in the report's own §3 table, and the sizing set next door doesn't contain it. The coolant field carries the WS2-E1 conditionality; the cable table and the inverter rating row carry none.

**Why it matters.** WS6 inherits `mass_kg.hv_cables_kg = 22.8` and the cable table; WS7 would build the harness from it. If sustained crawl stands (E1 pending), the phase run under-carries the one case the whole cooling argument is built around; if it is descoped to 1-min, the S2-floor sizing is fine on cable thermal mass — but nothing on the record says which, for this member.

**Resolution.** Size the `inverter_to_motor` run at the crawl phase current (455 Arms → 240 mm² at 505 A, or paralleled conductors; ~+6.5 kg on the 400 V class) with the same treatment on the 800 V class (240 Arms scaled → 95 mm², ~+2.5 kg) so the trade stays fair; restate the inverter's continuous-current rating to cover 644 A_pk sustained (its computed Tj at the crawl point is fine — ~126 °C — so this is a rating-statement fix, not a hardware change); or explicitly condition both members on WS2-E1 exactly as the coolant field now is. No conclusion flips: the 400-vs-800 penalty moves ~13.8 → ~18 kg, still an order below the cell-count argument, and machine, thermal, and bus-window results are untouched.

### WS2-F12 — minor. §5's "energy-unlimited at every operating point in the window" outruns the chopper-run cable at the window top

At full duty at 435 V the bank absorbs 105 kW and the chopper-to-resistor run carries 435/1.8 = **241.7 A rms continuously** — above its 208 A sizing and its 70 mm² / 225 A ampacity. The ribbon is genuinely steady-state at 105 kW; the cable is not: cable-limited continuous absorb is ~91 kW (225² × 1.8). The R2 requirement (50 kW, 167 A rms, voltage-independent) is met with wide margin, and WS2-E5's second-stage use is transient (seconds, against minutes-scale cable time constants), so nothing operational breaks — but the "literal" energy-unlimited claim should be qualified "cable-limited above ~91 kW continuous," or the run sized up one gauge (95 mm², ~+0.6 kg). The 800 V class does not share the issue (127.6 A vs 140 A ampacity).
